# src

The program's source code, split by purpose:

| Folder | Contents |
|---|---|
| `Application/` | Startup, paths, and shared app plumbing |
| `Config/` | Settings and saving them to disk |
| `Services/` | Talking to Windows: windows, processes, thumbnails, sounds, hotkeys |
| `Presenters/`, `Views/` | Logic and interfaces for the thumbnail windows |
| `UI/` | The settings window, its tabs, the tray icon and the Intel Watcher map window |
| `Universe/` | Universe map data loading and intel-message parsing |
| `Main.cpp` | Program entry point |
